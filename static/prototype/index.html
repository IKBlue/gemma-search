补充时发现并修掉的缺陷

你给的三页里共有 21 个 data-demo 按钮与 14 处 onclick="toast(...)"， 但没有任何一页定义 toast()，也没有 data-demo 的处理器—— 点这些按钮会抛 ReferenceError，表现出来就是"没反应"。

处理：抽出共享 app.js（toast + data-demo + 弹窗开关 + Esc 关闭），三页一次修好，不再各写一份。

领域差异清单（迁移到 React + TS 时的必办项）

#原型里的假设我们的实际原型状态
1一个图库，一张卡片多库 + 注册表 + compat 一致性校验待补
2图片就是终点每张图配一个同名压缩包，包才是产物已补字段
3按内容分类（人物/风景/建筑）按渲染器分类（VR / CR / CR+VR / 其他 / 未分类）已补
4尺寸 3840×2560 是重要信息尺寸无关紧要；要的是包名、体积、ID、日期已补
5相似度"98% 匹配"余弦 0.74~0.94，且分区间有意义（同款 ≥0.88 / 文本 0.74~0.80）已补
6无写入操作可写库：入库、改目录、改 ID、替换图、移出库已补页
7无"操作可恢复"概念事务 + 审计 + 撤销 + 待处理（RECOVERY_NEEDED）待补
8索引只是进度条索引有 revision / 权重精度 / 预处理版本 / seq 绑定与失败项待补
9无健康度概念图无包 / 包无图 / 扩展名与内容不符（实测 105 张） / 重复内容（实测 5 组）待补

「待补」= 差异已在本总览登记，但三页原型尚未改写；迁移到 React 时按 UI-REVIEW-and-migration.md §3 执行。
