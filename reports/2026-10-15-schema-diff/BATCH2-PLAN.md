## 0. 每张卡都必须做的四件事（跨切面）

1. **加一条迁移**（库级 `migrations.ts` / 应用级 `app-migrations.ts`）+ 推版本号；
2. **`schema-layers.ts` 里点名**该表归属哪一层（空层允许为空）；
3. **`db-schema.test.mjs`**：表数断言随之变化（6 → 6+n），**「每张建出的表都必须被点名」仍强制**；
4. 若新增 IPC 方法 ⇒ **`SPEC §5.1` 的「新增」清单同步**（契约变更，仍属"新增=兼容"）。

⚠️ 顺序纪律：**一次只开一张卡**（`migrations.ts` 与 `schema-layers.ts` 是共享写入面）。

## 1. 建议顺序（按"功能承诺的强度"排，不按表数）

| # | 卡 | 表 | 解锁的功能 | 为什么排这个位置 |
|---|---|---|---|---|
| **B2-1** | 任务台账 | `job` | 进度**持久化** · **断点续跑** · 取消 · **崩溃恢复** | SPEC 明写「进度单调且**不静默**」；现在进度只活在内存，崩了就没 ⇒ 属**功能承诺** |
| **B2-2** | 交付与取件**留痕** | `asset_export` | F6 的「已复制 / 已跳过 / 失败」三分类 + 历史列表 | 现在 `collect` 把文件复制出去却**什么都不留** ⇒ 也是**功能承诺** |
| **B2-3** | 条目标注（评分/备注/收藏） | `asset_user_meta` | 详情页"组织"块 | 资产管理最常摸的功能；**只 1 张表**，性价比最高 |
| **B2-4** | 体检台账 | `health_run` · `health_finding` | 体检历史 + **`state-cache-drift` 对账** | 体检本身（`libraryHealth`）已保留；缺的是"历史"与"对账" |
| **B2-5** | 搜索与历史 | `asset_name_fts` · `recent_query` · `recent_view` | 文件名子串搜（FTS5）· 搜索历史 · 接着上次看 | 现在按名找只能 `LIKE`；FTS5 已实测可用 |
| **B2-6** | 设置落库 | `app_setting` | 外观 / 模型目录 / 快捷键持久化 | 现在落 `config.json`（被 SPEC 定义为"兼容回退"） |
| **B2-7** | 标签与集合 | `tag` · `asset_tag` · `collection` · `collection_item` | 标签（可按标签找）· 集合（**F6 交付依赖**） | 4 张表、改动大，且与 B2-3 同属"组织"体验 |
| **B2-8** | 操作记录 | `activity` | 操作记录页 | 与 `asset_export` 不重复（一次批量 = activity 1 行 + export N 行） |
| **🔒 B2-9** | 文档检索 | `doc_dir` · `document` · `doc_chunk` | F7 | **进入条件**：先拿 10–30 份**真实文档**（现在语料不存在） |

## 2. 每张卡的验收要点（**能红**才算）

| 卡 | 关键验收（至少一条能红） |
|---|---|
| B2-1 | 心跳过期 ⇒ 启动时被判 `failed`（否则界面永远显示一个不存在的进度）· 游标续跑不重复已处理项 · `phase` 变化可见 |
| B2-2 | 一次批量 ⇒ `batch_id` 相同、行数 = 条数 · `uid` 置空后历史**仍可读**（`asset_name` 快照）· 三分类各自有落点 |
| B2-3 | 评分 NULL ≠ 0（未评 vs 0 分）· 重扫**不覆盖**人工值 |
| B2-4 | 两次体检 ⇒ 两条 `health_run` · `check_id='state-cache-drift'` 能报出物化值与重算值的差异 |
| B2-5 | 搜同一文本 3 次 ⇒ `recent_query` **1 行**（哨兵/偏唯一）· 超过上限修剪 · 中文子串命中 |
| B2-6 | 改外观 ⇒ 重启后仍在（且 `config.json` 不再是权威） |
| B2-7 | 标签改名一处生效（实体化）· 反查"这个标签下有哪些"走索引 · 集合允许同名 |
| B2-8 | 一次批量操作 ⇒ 1 行 activity；**不存渲染好的文案**（文案只有一份） |
| 🔒 B2-9 | 进入条件不满足 ⇒ **不开工**（不是"先建空表"） |

· 顺序是**按功能承诺强度**排的，不是按工量或依赖实测（没有跑过任何 B2 的表）；
