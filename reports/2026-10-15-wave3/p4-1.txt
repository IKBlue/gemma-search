2. Button 改了什么（逐条）
=================================================================================
· 变量 `button` → **`buttonVariants`**，并 `export { buttonVariants }`（shadcn 约定：别的组件/页面可以拿它
  把按钮样式套到 <a>/<Link> 上；同文件 `export default Button` 保留 ⇒ 10 个既有 import 点不用改）。
· 两个渲染分支都加 `data-slot="button"`（shadcn v4 的样式钩子/测试挂点；本仓库之前没有）。
· `asChild` 仍然渲染 **`<Slot.Root>`**（统一包的 Slot 是命名空间对象；写 `<Slot>` 会 React #130 白屏，
  回归断言在 dom-validity V3 —— 本轮复跑仍绿）。
· **变体与尺寸一个字没改**：default / primary / outline-accent / icon × md / sm / none。
  ⚠️ 没照抄 shadcn 的 secondary/destructive 变体，也没照抄它的 `h-9`/`h-10` 等高线 ——
     本项目的 `min-h-11` = 44px 是 **Apple HIG 命中区**要求，且 `styles.spec.mjs` 的 E4-a/b/c
     用真窗口 getComputedStyle 把它钉住了。

4.2 改了 D-C 的一条断言（Lead 已批准；**不是放宽**）
  改前：
    for (const dep of ['@tanstack/react-virtual', 'lucide-react']) {
      assert.equal(importers(dep).length, 0, `${dep} 应报零 import`)
      assert.ok(!declared[dep], `${dep} 已在 T4 删除，不该又被声明回来`)   // ← 会拦已批准的 P4 工作
    }
  改后：
    for (const dep of ['@tanstack/react-virtual', 'lucide-react']) {
      assert.equal(importers(dep).length, 0, `${dep} 在接线前应报零 import`)   // ← 判据**没动**
      assert.ok(IMPLICIT[dep], `${dep} 已声明 ⇒ 必须在 IMPLICIT 白名单里并写明用途`)
      assert.ok(!orphanAllowed(dep), `${dep} 不该出现在「零 import 且不在白名单」的名单里`)
    }
  为什么这不是放宽：「没人用」的判据（importers === 0）**原样保留**；被换掉的只有「不许声明」这一条 ——
  而它当初成立的前提是「这些包是历史遗留、零 import」，现在 P4 正式要用它们。
  力量没有下降：新 D-I 把「白名单必须给理由」再钉一遍，且 D-A 的判据抽成 `orphanAllowed()` **同一份**复用。
