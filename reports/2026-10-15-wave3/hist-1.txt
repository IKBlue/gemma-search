【契约与 SPEC 建议措辞】
```
recentQueries { limit? }                  → { rows: [{ q, scopeLibId, at, hits }], total }
activityList  { limit?, offset?, kind? }  → { rows: [{ id, kind, subjectKind, subjectId, at, result, detail }], total }
exportList    { libId?, limit?, offset? } → { rows: [{ exportId, batchId, uid, kind, at, outcome }], total }
```
· 「`recentQueries` / `activityList` 读**应用级** app.db；`exportList` 读**库级** .gs.db（需 `libId`）。三者都**只读**：
  库不存在 ⇒ `DB_MISSING`，**不得**顺手建库/迁移。」
· 「返回**时间降序**；**同毫秒必须按主键降序裁决**（`query_id`/`activity_id`/`export_id`）——
  只按时刻排序时同毫秒顺序不稳定，用户会看到"历史顺序自己变了"。」
· 「`total` 是**筛选后**总数；`offset` 越界返回**空数组**且 `total` 仍如实（不截断成"没有更多"）。」
· 「`activityList.kind` 可选筛选；`limit` 1..200（缺省 50）。」
