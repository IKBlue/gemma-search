# B · 配对正确性（独立按磁盘重算）

方法：不读索引，直接遍历素材库，按「同目录 + 同名主干」重算配对，再与索引自述比对。
判定要点：**索引声称的配对若与磁盘事实不符，任何情况下都是错**；而「磁盘有、索引没有」只在索引为全量时才算错。

| 项 | 磁盘（独立） | 索引（自述） |
|---|---|---|
| 预览图 | 3594 | 3594 |
| 压缩包 | 3594 | 3594 |
| **成功配对** | **3594** | **3594** |
| 有图无包 | 0 | 0 |

索引规模：3594 / 磁盘 3594 → 全量

## 差异

- ✅ 索引声称的 3594 对**全部**能在磁盘上独立复现；无矛盾
