## 1. 目标与成功标准

**目标**：把 `G:\model` 变成一个能"用一句话找到、并直接把包取出来"的本地工具。

**成功标准（可测，逐条验收）**

| # | 标准 | 验收方式 |
|---|---|---|
| 1 | 双击启动 ≤ **5 秒**出可用窗口 | 打包环境计时。**模型后台载入期间搜索的行为必须定义**（见下）|
| 1b | **模型载入中就搜索**：请求**排队**并显示「模型载入中，稍候」（**不静默失败、不假装没结果**）| P2 定义、P3b 验收 | |
| 2 | 文本查询（热）**P50 ≤ 80 ms / P95 ≤ 150 ms**（与图像对称）；图像查询（热）**P50 ≤ 1.0 s / P95 ≤ 1.5 s** | `docs/spec/SPEC-acceptance.md` §3 计时边界 |
| 3 | 结果以缩略图网格呈现，**应用内直接可见** | 缩略图零 404 |
| 4 | 任一条可一键在资源管理器**定位**其压缩包 | 人工确认 |
| 5 | 可把包**复制**到指定目录（默认 `E:\素材待用\`） | 人工确认 |
| 6 | 能**入库**新素材并索引；能管**增量** | 入库后立即可检索 |
| 7 | 增删查改齐备；「删」只提供**移出库**（可还原） | 移出后可从 `E:\移出素材\` 原样还原 |
| 8 | 支持**多库**；跨库检索只合并 `compat` 一致的库 | 故意注册 seq 不一致的库，确认被排除且原因可见 |
| 9 | **断网可用**；对素材库的写入只经入库/事务流程 | 断网全功能；扫描前后库指纹一致 |

> 完整定义见 `docs/spec/SPEC-app.md` §9。**不要在这里改标准，改规格。**
